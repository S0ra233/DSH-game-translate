# DSH-game-translate 使用说明

目标 DSH 0.2.1-rc.3 / Cordis ~4.0.5。插件不自动开始付费模型请求；升级保留已有 Cordis 配置和翻译数据。

[返回 README](../README.md) | [English guide](usage.en.md)

## 安装与配置

PowerShell 7：

如果安装过旧名 `dsh-translate`，请先停用或移除旧插件，再启用 `dsh-game-translate`，避免同名命令重复注册。沿用原有 `dataDirectory` 可继续使用已有工程和模型记录。

```powershell
dsh plugin --profile desktop add 'C:/Plugins/DSH-game-translate/dsh-game-translate-<version>.tgz'
dsh --profile desktop
```

profile 不是 desktop 时改为实际名称。若全局没有 dsh，使用原来启动 DSH 的入口管理插件，不必另装全局副本。需要命令、工具、Skill、llm、credentials 服务；子 Agent 翻译还需 subagents。没有子 Agent 时可以选主 Agent 翻译。

Windows 窗口恢复上一版 React 界面，由 WPF / Windows Desktop Acrylic 提供底层材质，透明的 WebView2 合成控件承载原有界面；不使用 PySide6 / QtWebEngine。需要已安装 WebView2 Runtime，Core 仍使用配置的 Python。目录按钮由窗口打开现代 Windows 文件夹选择器，确认后交回原根对话。

关闭后最多暂存一个窗口，60 秒内重开同一对话可复用；超时、DSH 退出或插件卸载释放。隐藏时停止材质计时器、停止状态刷新并请求挂起网页。

需要 Node.js 24.9+ 和 Python 3.10+。默认解释器 python；若 Windows 指向错误解释器，可在目标 profile 用户 patch 覆盖配置。DSH 替换整行 config，需重述所有需要的键：

```yaml
- id: dsh-game-translate
  config:
    pythonExecutable: 'C:/Python311/python.exe'
    dataDirectory: 'C:/TranslationData/DSH-game-translate'
    allowedGameRoots: []
    allowedWorkRoots: []
    timeoutMs: 900000
    cancelGraceMs: 5000
```

显式 dataDirectory 可在升级时保留绑定和模型记录。默认是插件自身 `.local`；更新时保留已有状态，不要替换为空目录。上面仅为示例，未改你的解释器配置。引擎依赖沿原 Skill 按游戏检查，Python 可用不等于所有外部解包工具已齐全。

## 使用流程

在工作目录根对话输入 `/翻译` 或选择同名候选，仅打开窗口，不发模型请求。裸 `/translation` 也映射到窗口；带参数的 `/translation status` 等仍走后台功能。

右上 `•••` 包含选择目录、初始化、翻译、封装写回、设置；菜单底部切换纯白 / 玻璃。主界面不显示目录路径或“已绑定”，未初始化提醒成功后消失。

选择目录打开系统文件夹窗口。已绑定时先提醒，取消确认或取消选择均保留原绑定。选定不同游戏后解除当前绑定，新目录需重新初始化；旧 WORK 和译文保留。pending 时不能从菜单切换，先在原聊天停止并核对。

初始化确认后进入同一 Agent 收件队列，不等于模型已开始。解包、依赖处理和错误在原聊天。实际资源登记或 Core 工程建立后才锁定；prepare 报错保留产物并释放 pending，修复后可重试。主 Agent 使用通用工具解包后，需要 translation_register_resources 登记真实文件，不能仅口头宣布成功。

也可以在原聊天让 Agent 换游戏：translation_begin_initialization 返回切换提醒，按 Skill 解包并登记成功后同步窗口。此路线新资源成功前保留旧绑定。工作区外且未授权的路径，需你先通过目录选择或 `/translation allow-game` 授权；Agent 不能自行增加授权范围。

每对段落对应同一真实 Task。左原文、右为已提交 Core 的译文，未译侧留白；临时草稿或模型流片段不会冒充正式结果。待复核保留标记。读取分页，Agent 状态结束、重新聚焦窗口或打开更多菜单时刷新，不做空闲定时查询。

说话人元数据与其对应台词合并显示为 `人名 [台词]`，人名弱化为蓝灰色，不再单独占一段；旁白不添加人名或方括号。Core 中原有说话人 Task 保留以便正常写回。

译文平时正常显示，鼠标悬停后点击右侧铅笔进入修改；双击仍用于文字选择。点击保存或 Ctrl+Enter 保存，取消或 Esc 放弃本次输入，编辑框内可切换修改对应人名。原文只读；编辑时暂停自动刷新并暂时禁用场景切换和更多操作，完成后恢复。手改不调用 Agent 或模型，通过同一 Core 保护控制码/术语、生成草稿记录并提交；版本冲突或校验失败会保留输入并提示，不覆盖已有新译文。修改后仍需在封装流程中确认写回。

“翻译…”列出仍有未翻译 / 待复核内容的阅读组，默认当前待处理组。组内保留原标签/分支分节，原 Scene 和 Task ID 不变。选择主 Agent，或子 Agent / 其他模型（可继承主模型）。主 Agent 导出真实包、发派 DSH 子任务、读取终态、审校后提交。特殊范围、单条重翻在原聊天提出。

核对译文后“封装写回…”选择输出父目录，插件生成尚不存在的新子目录并展示。确认只对当前工程、绑定版本、输出位置生效；主 Agent 调用原 Skill/Core 创建独立副本并读回。不覆盖源游戏，不自动启动游戏；读回通过不等于字体与运行验收。

## 设置

外观支持纯白 / 玻璃、系统 / 衬线字体、12–24 px、三档行距、35:65 至 65:35 栏宽。玻璃设置仅提供“乳白”和“柔光”，默认 5% 和 15%，范围均为 0–80%；边缘反光 100%、高光范围 100%、阅读区白度 20% 固定。恢复默认会保留当前风格并重置其余外观。旧版“磨砂强度”自动迁移，不再显示原说明小字。原生外观保存于 dataDirectory/native-appearance.json，网页回退入口使用 localStorage；工程绑定由 Host 管理。

“设置 → 翻译模型”填写名称、协议、API 基址、API Key、模型 ID。支持多条模型，点击已有名称编辑，编辑 Key 留空保留原值。高级上下文 / 输出上限是运行预算，应按实际模型填写；默认 65536 / 8192 不代表服务商承诺的容量。

下拉框再次点击同一按钮收起，也支持外点、Esc 和方向键。输入框使用中性焦点边框；API 填写会清理首尾空格，默认隐藏密钥，不会因保存而发起模型请求。

| 协议 | 基址示例 |
|---|---|
| OpenAI Chat Completions | https://api.example.com/v1 |
| OpenAI Responses | https://api.example.com/v1 |
| Anthropic Messages | https://api.anthropic.com |
| Gemini generateContent | https://generativelanguage.googleapis.com/v1beta |

兼容服务使用自己的 HTTP(S) 基址，Key 单独填写，不放 URL、参数或模型名称。Key 保存在 DSH credentials，不回传明文、不存 localStorage/模型 JSON、不交给主 Agent。是否加密落盘取决于 DSH 凭据后端，不额外声称系统钥匙串加密。保存不会进行付费连通性测试；服务需符合所选协议，并支持 DSH 的工具调用/结构化输出。定价未知，占位 cost 0 不代表免费或实际账单。

## 故障与反馈

初始化报错看原聊天。translation_status / translation_job 默认摘要，诊断和日志路径用 detail="full"；已就绪工程的报告用 translation_read_report 按需分页读。已被 Agent 消费的初始化回合错误 / 中断，读取状态时按 request_id 恢复；排队请求不会因无关回合结束而被清除。重启后状态不明或 Agent 正常结束却未完成时，先核对作业，再明确使用 translation_abandon_initialization 结束，不同时重跑同一 WORK。

Windows 使用独立系统窗口，非 Windows 网页入口才提供宿主内浮窗回退。关闭窗口不取消任务，停止仍在原聊天。退出 / 刷新 DSH 页面会关闭自有翻译弹窗，重新打开读取持久工程。

反馈可包含 DSH 版本、入口能否打开、卡在哪一步、UI 提示、原聊天报错及协议类型，截图遮住 Key。先用可备份的小游戏验证初始化 → 翻译 → 独立副本封装即可。

自动检查采用离屏界面和无窗口通道，不使用付费模型。实际桌面观感、真实服务商和游戏运行显示由用户实测。升级后先保留未保存输入，再完整退出并重新打开 DSH。
